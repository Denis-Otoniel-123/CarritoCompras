# Mi Carrito de Compras En Linea



## Screenshot

:heavy_check_mark: :heavy_check_mark: :heavy_check_mark: Aquí está demostrado como quedaria al finalizar el carrito de compras:

Pantalla principal donde los usuarios pueden ver productos destacados, acceder a su carrito y navegar por categorías. Incluye opciones de búsqueda y enlaces a ofertas especiales.

## :credit_card: :credit_card: :credit_card: Carrito de compras tras agregar productos.
Sección donde los usuarios pueden revisar los productos seleccionados, modificar cantidades, eliminar artículos y ver el total de la compra. También incluye opciones para proceder al pago.

![Logo del Proyecto](https://github.com/Denis-Otoniel-123/CarritoCompras/blob/main/Screenshot/Productos.JPG)


## :man: :man: :man: Pantalla Principal – Dashboard de Usuario administrador

Interfaz central que muestra un resumen de las métricas clave, como ventas totales, pedidos recientes y estadísticas de usuarios. Desde aquí, el administrador puede acceder a funciones para gestionar productos, realizar seguimientos de inventario y analizar el rendimiento del negocio.
